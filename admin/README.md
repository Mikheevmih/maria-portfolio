# Админка сайта-портфолио Марии Денисовой

- Публичный сайт: https://mikheevmih.github.io/maria-portfolio/
- Админка после объединения PR: https://mikheevmih.github.io/maria-portfolio/admin/

## Что готово

Интерфейс админки расположен в `admin/index.html` и размечен `noindex, nofollow`. Вход, сохранение текстов и ссылок в `index.html` и обновление `photo.jpg` работают через отдельный API в `admin/worker.js`. Все изменения публикуются коммитами в GitHub и затем автоматически разворачиваются GitHub Pages.

На странице редактирования можно изменить любой видимый текстовый узел `index.html`, все ссылки и фотографию. Предпросмотр содержит десктопный и мобильный режим. Сложные правки оформления лучше продолжать делать через GitHub.

## Безопасность

GitHub Pages — статический хостинг, поэтому проверки паролей на нём нет. **Нельзя хранить пароль в публичном GitHub-репозитории**, даже в конфигурационном файле `admin/config.json`. Он будет доступен посетителям.

Логин можно задать в публичных `admin/config.json` и `admin/wrangler.toml`, а пароль `ADMIN_PASSWORD`, ключ подписи сессии `SESSION_SECRET` и токен GitHub `GITHUB_TOKEN` нужно хранить **только** как Cloudflare Worker Secrets. Токен GitHub даёт право на запись, поэтому не отправляйте его мне и не добавляйте в README, историю коммитов или чаты.

Адрес `/admin/` открыт для просмотра формы входа. Метатег `noindex` просит поисковые системы не индексировать эту страницу, но не является механизмом защиты.

## Настроить Cloudflare (один раз)

1. Создайте аккаунт https://dash.cloudflare.com и установите Node.js.
2. Скачайте проект из GitHub или клонируйте репозиторий. Откройте терминал в папке `admin`.
3. Выполните:
   ```bash
   npx wrangler login
   npx wrangler deploy
   ```
   Cloudflare предложит авторизовать Wrangler и покажет опубликованный адрес Worker, например `https://maria-portfolio-admin-api.<subdomain>.workers.dev`.
4. Создайте три секрета (не показывайте значения другим людям):
   ```bash
   npx wrangler secret put ADMIN_PASSWORD
   npx wrangler secret put SESSION_SECRET
   npx wrangler secret put GITHUB_TOKEN
   ```
   - `ADMIN_PASSWORD` — длинный уникальный пароль, лучше 16+ символов.
   - `SESSION_SECRET` — случайная строка не меньше 32 байт. Сгенерировать можно командой `openssl rand -hex 32`.
   - `GITHUB_TOKEN` — fine-grained personal access token для репозитория `Mikheevmih/maria-portfolio` с разрешением **Contents: Read and write**; желательно установить срок действия.
5. В `admin/config.json` задайте `apiBaseUrl` как опубликованный HTTPS-адрес Worker **без слэша в конце**. Сохраните изменение в GitHub.
6. В настройках GitHub Pages выберите **Deploy from a branch → main → /(root)**. Объедините pull request в `main`. После публикации откройте страницу `/admin/` и войдите.

Обратите внимание: конфигурация Worker уже указывает допустимый origin `https://mikheevmih.github.io` и репозиторий. Если измените адрес сайта, обновите `SITE_ORIGIN` в `admin/wrangler.toml` и выполните `npx wrangler deploy` ещё раз.

## Как пользоваться

1. Откройте `/admin/`, введите адрес API, логин и пароль.
2. Выберите вкладку «Тексты», «Ссылки» или «Фотография».
3. При необходимости воспользуйтесь поиском, чтобы найти нужную надпись или ссылку.
4. Нажмите «Обновить превью» для предпросмотра и «Опубликовать» для коммита в GitHub.
5. Подождите, пока GitHub Pages обновит публичный сайт.

## Технические замечания

- Клиентская сессия живёт до 8 часов (токен хранится в `sessionStorage`). Для прекращения доступа раньше выйдите из админки, а при необходимости поменяйте `SESSION_SECRET`.
- На стороне API подписанный токен проверяется заново перед записью; GitHub token не попадает в браузер.
- Смена фотографии принимает JPG. Админка предварительно уменьшает и сжимает его.
- GitHub проверяет SHA предыдущей версии `index.html`. Если кто-то изменил сайт после загрузки админки, сохранение отклонится, чтобы не затереть чужую работу.
- Не публикуйте админку без настройки защищённого API. Для продакшена рекомендуется дополнительно включить rate limiting для `/login` в Cloudflare и двухфакторную защиту аккаунтов Cloudflare и GitHub.
- Предпросмотр намеренно не запускает JavaScript исходного сайта, чтобы редактирование не исполняло непроверенный код.

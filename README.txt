МАРИЯ ДЕНИСОВА · PORTFOLIO · LUMINOUS BLUE
========================================

Это одностраничный сайт на HTML/CSS/JavaScript. Всё содержимое основано
на резюме «Мария Денисова CV 09.2026.docx.pdf».

КАК ОТКРЫТЬ
1. Распакуйте архив.
2. Откройте index.html двойным щелчком в браузере.
3. Интернет нужен только для загрузки веб-шрифта. Основная верстка и
   интерактивность работают локально.

КАК ДОБАВИТЬ ПОСТОЯННУЮ ФОТОГРАФИЮ
1. Положите в ту же папку фотографию Марии с названием photo.jpg.
2. Обновите страницу: фотография заменит декоративную заглушку.
3. Кнопка «Примерить фото Марии» позволяет выбрать снимок только для
   просмотра в текущей вкладке: после перезагрузки выбор не сохраняется.

ЧТО УЖЕ ПЕРЕНЕСЕНО ИЗ РЕЗЮМЕ
— Имя, специализация, 5 мест работы с датами и ролями.
— Шесть результатов и шесть кейсов из X5 Digital, МТС, Мегамаркета, Ozon.
— Образование РГГУ (2025, 2026) и английский B2.
— Электронная почта, телефон, Telegram из активной ссылки внутри PDF.
— Переходы на Sostav, Workspace Digital 2026, лендинг 5ka.ru.

ВАЖНО ПЕРЕД ПУБЛИКАЦИЕЙ
— Добавьте реальный портрет и, по желанию, визуальные материалы проектов.
— Уточните формулировки, согласуйте публикацию кейсов и метрик, если нужно.
— Проверьте контакты и ссылки; они предназначены для публичного сайта.
— При изменении фактов редактируйте текст непосредственно в index.html.

КАК ОПУБЛИКОВАТЬ
Сайт статический, его можно разместить на GitHub Pages или Netlify.
Отдельный сервер и база данных не нужны.


Обновление: в папку уже встроена реальная фотография Марии (photo.jpg). При желании её можно заменить своим файлом с тем же названием или через кнопку «Заменить фото» прямо на странице.
